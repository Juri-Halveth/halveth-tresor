# HALVETH Tresor

**Краткий путеводитель по проекту · EN / RU**

Локальное настольное хранилище учётных данных для Windows. Исходная README описывает зашифрованное хранение паролей, ключей и параметров подключения, включая организацию записей, поиск, разблокировку, восстановление и настольные сборки.

Перед использованием конкретной сборки или её распространением прочитайте документацию безопасности и карту лицензий по версиям. Исторические разрешения MIT, новые материалы HALVETH и уведомления о зависимостях описаны отдельно; публичный репозиторий не означает единую лицензию для всех версий.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.
