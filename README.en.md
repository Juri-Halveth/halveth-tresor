# HALVETH Tresor

**Concise project guide · EN / RU**

A local desktop credential vault for Windows. The original README describes encrypted storage for passwords, keys and connection details, including organization, search, unlocking, recovery and desktop builds.

Read the security documentation and versioned licence map before relying on or redistributing a particular build. Historical MIT grants, new HALVETH contributions and dependency notices are documented separately; a public repository is not a blanket licence for every version.

This manually edited guide summarizes the audited source. The original technical documentation remains the reference for commands, build requirements, exact versions and detailed evidence.
